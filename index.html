Sauvegardes Cloud

Sauvegardes Cloud est une application personnelle permettant d'automatiser la sauvegarde de fichiers entre différents services de stockage cloud.

Fonctionnement

L'application utilise des scripts Python exécutés automatiquement avec GitHub Actions.

Elle permet notamment :

  • La récupération de fichiers depuis pCloud.
  • Leur sauvegarde dans Google Drive.
  • Leur sauvegarde dans Dropbox.
  • L'envoi de rapports par Gmail.

Utilisation

Cette application est destinée exclusivement à un usage personnel et privé.

Elle n'est pas commercialisée et ne propose aucun service au public.

Protection des données

Les données sont traitées uniquement pour réaliser les sauvegardes autorisées par le propriétaire des comptes concernés.

Les fichiers personnels, les identifiants et les jetons d'accès ne sont pas publiés sur ce site.
